    domain_r_rnk¶

    Domain rank over Great Britain, 1 is the healthiest.

    Type: int32 (SQL Server int). Nullable: yes. Group: domain ranks. Editions: 2, 3, 4, 5.1; NULL in 1.

    What it is, by edition¶

    Editions Definition Unit Source
    2, 3, 4, 5.1 Rank of the retail domain score over Great Britain: 1 is the healthiest area. Minimum ranking (ties share the lowest rank), except version 4's five health indicator ranks, which are dense. rank our wording, decision ranks-gb-only

    Why¶

    • one-table-all-editions: One table, ahah_datazone, keyed by (ahah_version, datazone_code), one row per Scottish data zone per edition, with datazone_vintage. All five editions (1, 2, 3, 4, 5.1) are carried.
    • v5-1-names: Column names are those of the version 5.1 file. Earlier editions map onto them by an explicit per-edition mapping (mapping.yaml) that names every file column exactly once.
    • ranks-gb-only: Ranks, percentiles and deciles are stored as published, over Great Britain. No Scotland-only rank is computed.

    Export¶

    CSV column domain_r_rnk, in every row of ahah_datazone.csv.gz; SQL Server type int; part of the row digest (docs/sql/check_loaded_digest.sql). An absent value is an empty cell and NULL.
