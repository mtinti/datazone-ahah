# Data dictionary: `ahah_datazone`, schema `ahah_datazone_v1`

One row per Scottish data zone per AHAH edition. Key: `ahah_version`, `datazone_code`. Column names are
those of the version 5.1 file; earlier editions map onto them (the "File column" columns below).
A column an edition does not publish is NULL for it. Generated by `python -m ahah_ingest.dictionary`; do not edit by hand.

## Conventions

- UK Open Government Licence v3.0, access tier Open on GeoDS; registration required to download.
- Every rank, percentile and decile reads 1 as the healthiest area. This is the opposite of SIMD, where 1 is the most deprived.
- Ranks are over Great Britain: 41,729 areas in editions 1 to 3, 42,648 in 4, 43,064 in 5.1. A rank is read with its edition.
- Indicator percentiles run 0 to 100 (101 values), domain and index percentiles 1 to 100. See `PERCENTILES.md`.
- Editions are not comparable with each other: methods, units and geography change. Use one edition per study.
- Editions 1 to 4 are on the 2011 data zones (6,976), edition 5.1 on the 2022 data zones (7,392). The vintages do not nest.
- Scores and indicators are `decimal(38,20)`, stored exactly as published, never through a float.

## Units and definitions by edition

- **Version 1** (2016): Accessibility indicators are network distances in kilometres. Passive green space is an area measure of green space within a 900-metre buffer, unit not stated by the paper (Daras et al. 2019); the Scottish values run 0 to 277.5, so it is not a share. Air: annual mean concentrations. The environment domain includes green space as well as the air pollutants.
- **Version 2** (2017): Units unconfirmed: the version 2 documentation is not held. The column names suggest the revised method. Eleven routed indicators and their deciles hold -1 in S01010206 and S01010226, the likely code for no route; exclude it before averaging. `ur` is a 0/1 flag the build code does not use, probably urban = 1, undocumented.
- **Version 3** (2022): Accessibility: drive time in minutes. Passive green space: median NDVI. Air: annual mean µg/m³ (v5 methodology, sections 3 and 5). Values may be written in scientific notation in the file; they are stored exactly.
- **Version 4** (2024): As version 3; values are published to 4 decimals. The five health indicator ranks are dense (ties share a rank and the next rank follows), so the largest health rank is below the number of areas. Zone S01008132 has an air quality domain score of exactly -1.0000, an ordinary value.
- **Version 5.1** (2026): As version 3, with a 15th indicator, active green space, and a hospital defined as one with an accident and emergency department, as in version 1 (Daras et al. 2019, page 3); versions 3 and 4 do not state the selection. Values carry up to 20 fractional digits.
